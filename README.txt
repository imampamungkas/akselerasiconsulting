CARA UPLOAD KE HOSTING:
-----------------------

1. Login ke cPanel hosting.

2. Buka File Manager.

3. Masuk ke folder public_html.

4. Upload semua file website dan folder assets.

5. Pastikan index.html berada langsung di dalam public_html.

   Contoh:

   public_html/
       index.html
       about.html
       services.html
       contact.html
       assets/

6. Jangan sampai file index.html berada di dalam
   folder tambahan seperti:

   public_html/akselerasiconsulting/index.html

   kecuali memang ingin website berada di subfolder.

7. Buka domain:

   https://akselerasiconsulting.com


PENGUBAHAN LOGO:
----------------

Logo sementara menggunakan huruf "A".

Untuk mengganti logo:

1. Buka file HTML.
2. Cari bagian:

   <div class="brand-mark">A</div>

3. Ganti dengan logo image, misalnya:

   <img src="assets/images/logo.png"
        alt="Akselerasi Consulting"
        style="width:45px;height:auto">

4. Upload logo ke folder assets/images.

PENGUBAHAN FOTO:
----------------

Foto website menggunakan link Unsplash sementara.

Jika ingin memakai foto sendiri:

1. Upload foto ke assets/images.
2. Ganti URL gambar pada bagian <img>.
3. Contoh:

   <img src="assets/images/foto-tim.jpg"
        alt="Tim Akselerasi Consulting">
